The **SFTP** view is a dual-pane file browser: the left pane is this computer and the right pane is the remote host. It speaks SFTP, SCP (for servers with SFTP turned off) and FTP/FTPS with pinned certificates.

## Browsing and transferring

1. Choose a host at the top of the right pane and click **Connect**.
2. Click a folder in the breadcrumb to jump to it, or the pencil icon next to it to type a path.
3. Select files with click, **Ctrl**+click or **Shift**+click.
4. Drag files to the other pane, or use **Upload** and **Download**.
5. Right-click a file for open, download or upload, copy path, rename, permissions and delete.

Click a column heading to sort, and again to reverse. The filter box narrows the current folder by name. The eye icon shows or hides dotfiles. Folders are copied recursively, and symbolic links are listed but not followed during recursive copies. Transfers appear at the bottom with progress and a cancel button; the queue supports pause and resume.

Jump hosts and proxies apply to SFTP, so a host behind a bastion works the same way. See [Connecting](/docs/connecting).

### When a name already exists

A transfer asks what to do: **Replace**, **Skip** that file, or **Keep both** (the new one becomes `name (1).ext`). A folder you keep both of is copied beside the old one, not into it.

## Editing remote files

Double-click a file, or select it and press the edit button. It opens in this computer's default app for that file type. Each time you save, it is uploaded back, and the list at the bottom shows the last upload. Press **Stop** when you are done.

The local copy lives in a private temporary folder and is deleted when you stop, disconnect, lock the vault or quit.

## Other kinds of server

The same two panes browse whatever a host speaks.

### SCP

If a server has SFTP turned off, connecting says so and offers **Use SCP for this host**; the choice is saved on the host (or set **Files** to SCP in its form). SCP browses, uploads, downloads, renames, deletes and changes permissions, but cannot continue a partly copied file or open a file for editing, and a file name cannot contain a line break.

### FTP and FTPS

Choose **FTP / FTPS** as a host's protocol (port 21, or 990 for implicit TLS), pick the encryption, and tick **Anonymous** if the server takes no login; otherwise attach a user name and password.

- Explicit TLS (the default) and implicit TLS show the server's certificate the first time and trust it from then on, like an SSH host key. A different one later is refused before your password is sent.
- **None** works, but the tab says **UNENCRYPTED** and the password and files cross the network readable.
- Downloads and uploads continue where they stopped when you retry.
- Jump hosts and proxies are not used for FTP.

Each kind only offers what it can do: a server that cannot rename or delete does not show those buttons.

## From the terminal

Dropping a file on a terminal uploads it over SFTP to that pane's current directory, and Ctrl+click on a path in the output browses to it. See [Terminal](/docs/terminal).

## Example

```text
Host:    demo@example.com
Remote:  /srv/app/releases
Action:  drag app.tar.gz from the left pane to the right pane
```
